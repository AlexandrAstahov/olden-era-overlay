# Heroes of Might and Magic: Olden Era Arena Overlay Helper

Локальное desktop-приложение для Windows, которое анализирует экран игры **Heroes of Might and Magic: Olden Era** в режиме **Арена** и показывает визуальную подсказку поверх интерфейса игры.

## Цель проекта

Помочь игроку выбирать лучший вариант из доступных на экране (навыки, перки, герои и т.д.) на основе анализа текущего состояния арены. Приложение работает как **overlay-помощник** — только чтение экрана, анализ и отображение подсказки.

## Ограничения

Приложение **не должно**:

- выполнять автоклик;
- управлять мышью или клавиатурой;
- вмешиваться в память игры;
- делать инъекции в процесс игры.

Допустимо: захват экрана, распознавание (OCR/CV), локальный анализ, отрисовка overlay поверх окна игры.

| Компонент | Технология |

## Этапы разработки

1. **Стартовый workspace** — структура каталогов, документация, пустые JSON, `.gitignore`, инициализация Git.
2. **Сбор скриншотов** — инвентаризация экранов арены, разметка областей интерфейса.
3. **База знаний** — схема и первичное заполнение `skills.json`, `heroes.json`, `rules.json`.
4. **Прототип на скриншотах** — OCR/CV и парсинг без live capture.
5. **Decision engine** — правила выбора лучшего варианта на основе базы знаний.
6. **Overlay MVP** — прозрачное окно поверх игры с подсказкой.
7. **Live capture** — захват экрана в реальном времени вместо статичных скриншотов.
8. **Тесты и стабилизация** — регрессия на наборе скриншотов, доработка точности.
